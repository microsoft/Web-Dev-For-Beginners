## ਪ੍ਰੋਜੈਕਟ ਸਾਰਾਂਸ਼

ਇਹ ਸ਼ੁਰੂਆਤੀ ਵਿਦਿਆਰਥੀਆਂ ਨੂੰ ਵੈੱਬ ਵਿਕਾਸ ਦੇ ਮੁਢਲੇ ਤੱਤ ਸਿਖਾਉਣ ਲਈ ਇੱਕ ਸਿੱਖਿਆਮੁਖ ਰੀਪੋਜ਼ਟਰੀ ਹੈ। ਇਹ ਕੋਰਸ ਮਾਈਕ੍ਰੋਸਾਫਟ ਕਲਾਉਡ ਐਡਵੋਕੇਟਸ ਦੁਆਰਾ ਵਿਕਸਤ ਕੀਤੀ ਗਈ 12 ਹਫਤਿਆਂ ਦੀ ਇੱਕ ਵਿਸਤ੍ਰਿਤ ਕੋਰਸ ਹੈ, ਜਿਸ ਵਿੱਚ ਜਾਵਾਸਕ੍ਰਿਪਟ, CSS ਅਤੇ HTML ਦੇ 24 ਪ੍ਰਯੋਗਾਤਮਕ ਪਾਠ ਸ਼ਾਮਲ ਹਨ।

- **ਸਿੱਖਣੀ ਸਮੱਗਰੀ**: 24 ਸਤੰਰਬੱਧ ਪਾਠ ਜੋ ਪ੍ਰੋਜੈਕਟ ਅਧਾਰਿਤ ਮੋਡਿਊਲਾਂ ਵਿੱਚ ਵੰਡੇ ਹੋਏ ਹਨ

## ਸੈਟਅਪ ਕਮਾਂਡز

ਇਹ ਰੀਪੋਜ਼ਟਰੀ ਮੁੱਖ ਤੌਰ 'ਤੇ ਸਿੱਖਣੀ ਸਮੱਗਰੀ ਲਈ ਹੈ। ਵਿਸ਼ੇਸ਼ ਪ੍ਰੋਜੈਕਟਾਂ ਨਾਲ ਕੰਮ ਕਰਨ ਲਈ:

### ਮੁੱਖ ਰੀਪੋਜ਼ਟਰੀ ਸੈਟਅਪ

```bash
git clone https://github.com/microsoft/Web-Dev-For-Beginners.git
cd Web-Dev-For-Beginners
```
  
### ਕੁਇਜ਼ ਐਪ ਸੈਟਅਪ (Vue 3 + Vite)

```bash
cd quiz-app
npm install
npm run dev        # ਵਿਕਾਸ ਸਰਵਰ ਚਾਲੂ ਕਰੋ
npm run build      # ਉਤਪਾਦਨ ਲਈ ਬਣਾਓ
npm run lint       # ESLint ਚਲਾਓ
```
  
### ਬੈਂਕ ਪਰੋਜੈਕਟ API (Node.js + Express)

```bash
cd 7-bank-project/api
npm install
npm start          # ਏਪੀਆਈ ਸਰਵਰ ਸ਼ੁਰੂ ਕਰੋ
npm run lint       # ESLint ਚਲਾਓ
npm run format     # Prettier ਨਾਲ ਫਾਰਮੈਟ ਕਰੋ
```
  
### ਬਰਾਊਜ਼ਰ ਐਕਸਟੈਨਸ਼ਨ ਪ੍ਰੋਜੈਕਟ

```bash
cd 5-browser-extension/solution
npm install
# ਬ੍ਰਾਉਜ਼ਰ-ਖਾਸ ਐਕਸਟੈਂਸ਼ਨ ਲੋਡਿੰਗ ਨਿਰਦੇਸ਼ਾਂ ਦੀ ਪਾਲਣਾ ਕਰੋ
```
  
### ਸਪੇਸ ਗੇਮ ਪ੍ਰੋਜੈਕਟ

```bash
cd 6-space-game/solution
npm install
# index.html ਨੂੰ ਬ੍ਰਾਉਜ਼ਰ ਵਿੱਚ ਖੋਲ੍ਹੋ ਜਾਂ ਲਾਈਵ ਸਰਵਰ ਦੀ ਵਰਤੋਂ ਕਰੋ
```
  
### ਚੈਟ ਪ੍ਰੋਜੈਕਟ (ਪਾਇਥਨ ਬੈਕਇੰਡ)


### ਕੁਇਜ਼ ਐਪ ਤਿਆਰ ਕਰਨਾ (Azure Static Web Apps)

ਕੁਇਜ਼-ਐਪ ਨੂੰ Azure Static Web Apps ਲਈ ਸੰਰਚਿਤ ਕੀਤਾ ਗਿਆ ਹੈ:

```bash

npm run build      # dist/ ਫੋਲਡਰ ਬਣਾਉਂਦਾ ਹੈ
# ਮੈਂਨ ਵਿਚ ਧੱਕਣ 'ਤੇ GitHub Actions ਵਰਕਫਲੋ ਰਾਹੀਂ ਤਾਇਨਾਤ ਕਰਦਾ ਹੈ
```
  
Azure Static Web Apps ਸੰਰਚਨਾ:  
- **ਐਪ ਦੀ ਖੇਤਰਫਲ**: `/quiz-app`  
- **ਆਉਟਪੁੱਟ ਖੇਤਰ**: `dist`  
- **ਵਰਕਫਲੋ**: `.github/workflows/azure-static-web-apps-ashy-river-0debb7803.yml`

## ਡਿਬੱਗਿੰਗ ਅਤੇ ਸਮੱਸਿਆ ਸੂਚਨਾ

### ਆਮ ਸਮੱਸਿਆਵਾਂ

**ਕੁਇਜ਼ ਐਪ ਸ਼ੁਰੂ ਨਹੀਂ ਹੁੰਦਾ**:  
- Node.js ਵਰਜ਼ਨ ਦੀ ਜਾਂਚ ਕਰੋ (v14+ ਸਿਫਾਰਸ਼ੀ)  
- `node_modules` ਅਤੇ `package-lock.json` ਮਿਟਾ ਕੇ `npm install` ਚਲਾਓ  
- ਪੋਰਟ ਸੰਘਰਸ਼ ਦੀ ਜਾਂਚ (ਡਿਫੌਲਟ: Vite ਪੋਰਟ 5173 ਵਰਤਦਾ ਹੈ)  

**API ਸਰਵਰ ਚੱਲਦਾ ਨਹੀਂ**:  
- Node.js ਵਰਜ਼ਨ (node >= 10) ਸਹੀ ਹੋਵੇ ਜਾਂ ਨਾ  
- ਪੋਰਟ ਪਹਿਲਾਂ ਹੀ ਵਰਤਿਆ ਜਾ ਰਿਹਾ ਹੈ ਕਿ ਨਹੀਂ  
- ਸਾਰੇ ਡਿਪੈਂਡੈਂਸੀਆਂ `npm install` ਨਾਲ ਇੰਸਟਾਲ ਕੀਤੀਆਂ ਗਈਆਂ ਹਨ  

**ਬਰਾਊਜ਼ਰ ਐਕਸਟੈਨਸ਼ਨ ਲੋਡ ਨਹੀਂ ਹੁੰਦਾ**:  
- manifest.json ਠੀਕ ਫਾਰਮੈਟ ਕੀਤਾ ਹੋਇਆ ਹੈ ਜਾਂ ਨਹੀਂ
